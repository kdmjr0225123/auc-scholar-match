A Slack connector isn't linked to this account, so I can't stand the workspace up directly — but here's a 10-minute setup you can run yourself before tomorrow's call, plus the option to hook Slack in going forward.

## 1. Workspace
- Create (or reuse, if you already have one) a workspace named **Elevaid**.
- Invite Dallas and Trav by email as soon as it exists — don't wait until channels are built out.

## 2. Channels

| Channel | Purpose | Members |
|---|---|---|
| `#general` | Announcements, whole-team visibility | Everyone |
| `#dev` | Pipeline, repo, Supabase, anything technical | KJ, Dallas |
| `#growth-outreach` | SGA relationships, campus leads, visibility pushes | KJ, Trav |
| `#async-updates` | The Mon/Wed/Fri written check-ins from the operating cadence | Everyone |
| `#random` | Non-work, keeps the other channels clean | Everyone |

## 3. Pin on day one
- In `#general`: link to the [Sprint Board](#) (send the artifact link once you have it) and this week's sync agenda.
- In `#dev`: the repo link and a note pointing Dallas to his technical handoff doc.

- In `#async-updates`: a one-line pinned reminder of the format — "Mon/Wed/Fri: what moved, what's blocked, what's next."

## 4. Set the tone early
- Post a short welcome in `#general` framing the cadence: 2-week sprints, one weekly call, async updates Mon/Wed/Fri in between.
- Have Dallas and Trav each drop a one-line intro in `#general` — keeps it human before the work starts.
